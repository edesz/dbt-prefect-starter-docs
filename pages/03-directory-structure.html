NoteFiles Needed if Replacing Pixi with tox

If you prefer to switch the default choice of Pixi for managing Python environments, then the alternative option provided in this starter project is to use tox and uv with the tox-uv plugin. In this case, it is recommended to use using-uv > TOML, since the INI version is deprecated. The following files would be required

  1. py-env-tools/tox/using-uv/.gitignore
  2. py-env-tools/tox/using-uv/pyproject.toml
  3. py-env-tools/tox/using-uv/TOML/Makefile
  4. py-env-tools/tox/using-uv/TOML/tox.toml
